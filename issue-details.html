Checkout button not responding on mobile Safari

R
Riya M.
·
Reported 2 hours ago
·
142 views
·
8 comments

Description

The purchase/checkout button is completely frozen on iOS Safari 16 and above. When a user taps the "Buy Now" or "Complete Purchase" button on the checkout screen, the button visually depresses briefly but no action is triggered — no page transition, no loading state, nothing.

This is causing a massive drop in mobile conversion rates. Users are abandoning their carts at the final step. The issue does not occur on Chrome for iOS, only on Safari. Desktop Safari seems fine too.

I've cleared my browser cache, tried different network connections, and tested on multiple iPhone models (iPhone 12, 13, 14). All exhibit the same behavior.

Steps to Reproduce

  1. Open the website on iPhone using Safari (iOS 16+)
  2. Add any product to your cart
  3. Navigate to the Checkout page
  4. Fill in shipping details
  5. Tap the "Complete Purchase" button
  6. Nothing happens — button does not respond

Environment

iPhone 14 Safari 16.2 iOS 16.3
